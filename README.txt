FortisTeach simple i18n package

Upload these files to the root of a PUBLIC GitHub repository:
- fortisteach-translations.js
- fortisteach-i18n.js
- webflow-head-code.html

Then replace USERNAME and REPOSITORY in webflow-head-code.html and paste that code into the site's global Head Code.

Language controls:
- data-lang="en"
- data-lang="hy"
- data-lang="ru"
- data-current-lang
